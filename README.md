# Exercicio_API_tempo
 Relatório Climático Automatizado (API Open-Meteo)Este projeto é um script Python que automatiza a coleta de dados meteorológicos históricos e atuais. Ele se conecta a uma API externa, processa as informações e gera um relatório estruturado em formato visual e arquivo de dados.  
 🚀 Fluxo do SistemaO código está organizado em três etapas fundamentais de engenharia de dados:
 1. Preparação e RequisiçãoConexão com API: Utiliza a biblioteca requests para acessar o endpoint da Open-Meteo.  Parâmetros Dinâmicos: O usuário define a localização (latitude/longitude) e o período de consulta.  Dados Coletados: Temperatura máxima a 2 metros de altura e soma de precipitação (chuva).
2. Processamento e VerificaçãoTratamento de Erros: O sistema verifica o status_code da resposta. Apenas se o código for 200 (sucesso), o processamento continua.  Conversão JSON: Os dados brutos da API são transformados em dicionários Python para extração de informações específicas.  Estruturação com Pandas: As informações diárias são convertidas em um DataFrame, permitindo uma visualização tabular organizada e limpa.
3. Armazenamento e SaídaExportação CSV: O DataFrame é salvo automaticamente em um arquivo chamado relatorio_prof_luiz.csv para uso posterior em planilhas ou BI.  Exibição Visual: Utiliza a função display() para apresentar a tabela de dados formatada no console/notebook.
4. 🧠 Conceitos AplicadosManipulação de APIs: Uso de requisições HTTP do tipo GET com parâmetros estruturados.  Data Science: Utilização da biblioteca Pandas para análise e transformação de dados.  Pensamento Computacional: Decomposição do problema em etapas de entrada, processamento e saída.
5. 🛠️ Tecnologias UtilizadasPython 3  Requests: Para comunicação com servidores web.  Pandas: Para manipulação e análise de dados em formato de tabela.
